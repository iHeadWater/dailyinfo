# 论文配图 Skill

## 背景与目标

两个功能：
1. **论文配图**：为周报里每篇论文配一张图，插入到对应论文段落下方
2. **封面图**：根据整期周报内容生成一张横幅封面图，用作微信文章封面（thumb）

论文配图优先级：
1. **论文原图**：从 Zotero PDF 中提取核心图（架构图 / 方法流程图 / 最佳结果图）
2. **AI 生成**：提取不到时，调用智谱AI（CogView）生成学术风格示意图

## 工作流程

### 第一步：匹配 PDF

根据周报里的论文标题，在 `~/Zotero/storage/` 下遍历所有子文件夹，找文件名最匹配的 PDF。

匹配策略：
- 用论文标题关键词和 PDF 文件名做模糊匹配（相似度 > 0.3 才算匹配）
- 匹配不到，直接跳到第三步（AI 生成）

### 第二步：从 PDF 提取核心图

用 `pymupdf` 提取图片，按以下规则筛选：

| 优先级 | 图片特征 | 说明 |
|--------|---------|------|
| 高 | 宽度 > 300px，位于论文前半部分 | 通常是架构图/流程图 |
| 中 | 宽度 > 300px，位于论文后半部分 | 通常是结果图 |
| 跳过 | 宽或高 < 100px | 图标、logo、小装饰 |

取得分最高的一张，保存为 PNG。

提取失败（无合适图片）→ 进入第三步。

### 第三步：AI 生成示意图（备用）

调用智谱AI CogView-3 生成示意图。

提示词模板：
```
A clean scientific illustration for a research paper about: [论文一句话摘要].
Style: minimalist, flat design, blue and white color scheme, no text, suitable for academic WeChat article.
```

注意：
- 不在图里加文字
- 风格简洁学术，和公众号排版协调
- 尺寸 1024x1024

### 第四步：输出

每篇论文输出一张图，命名：`figure_[序号].png`

同时生成 `figures.json` 记录来源：
```json
{
  "figures": [
    {
      "paper_title": "论文标题",
      "figure_path": "figures/figure_1.png",
      "source": "pdf_extract",
      "note": "提取自第3页"
    },
    {
      "paper_title": "论文标题",
      "figure_path": "figures/figure_2.png",
      "source": "ai_generated",
      "note": "AI生成示意图"
    }
  ]
}
```

### 第五步：生成封面图

在所有论文配图完成后，调用 CogView 生成整期封面图，保存为 `figures/cover.png`，并上传为微信永久素材。

封面提示词系统（固定风格 + 动态内容 + 防重复随机变量）：

**固定风格**：科技感信息可视化，类似 arXiv/Nature Graphical Abstract + 科技媒体封面结合，主色调深蓝/靛蓝/青绿/白色，16:9 横幅比例。

**动态变量**（每期随机选取，防止重复）：

| 变量 | 候选池 |
|------|--------|
| 布局 | 2×2模块网格 / 2×3模块网格 / 左右分栏大图 / 中心辐射式 |
| 图标风格 | 线性图标 / 霓虹发光图标 / 轻拟物3D图标 |
| 核心隐喻 | 神经网络→河流水系 / Transformer→数据融合漩涡 / AI芯片→遥感轨道 / 深度学习层→山脉水文 等 |
| 图表组合 | 折线+散点 / 雷达+热力 / 桑基+柱状 / 环形+网络拓扑 |

**动态内容**：从本期导读提取前 150 字作为主题描述，注入 prompt。

**禁止项**：照片写实人物 / 论文截图 / 纯文字排版 / 图中出现任何文字字母数字。

注意：
- 封面生成后自动上传微信永久素材，替换默认封面
- 每次运行随机选取不同变量组合，避免视觉重复

## 跳过规则

和周报 Skill 保持一致，以下论文不配图：
- 周报里被跳过的论文（纯数学/理论推导、与团队领域无关）
- AI 资讯和工具栏目不配图

## 风格规范

- PDF 提取的图保持原始比例，不裁剪
- AI 生成的图统一加水印文字"示意图"（在图片右下角）
- 图片下方标注来源：`图源：论文原图` 或 `图源：AI生成示意图`

## 依赖

```
pip install pymupdf httpx zhipuai
```

环境变量：
- `ZHIPUAI_API_KEY`：智谱AI的 API Key（bigmodel.cn 申请，支持支付宝充值）
