# 周报生成 Skill

## 背景与目标

团队每周从 dailyinfo 系统筛选前沿论文和 AI 资讯，存入 Zotero，再经 NotebookLM 自动生成初稿 MD。但 NotebookLM 的输出往往内容过薄，缺乏方法细节和量化结果。

你的任务是：**接收 NotebookLM 的 MD，通过网络搜索补充细节，重构成高质量的公众号周报**。

读者是团队内部成员 + 外部技术从业者，风格介于严肃与轻松之间，在手机上阅读。

---

## 工作流程

### 第一步：评估输入质量

收到 NotebookLM 的 MD 后，快速判断每篇论文的信息是否足够：
- **足够**：包含问题背景、方法思路、关键数字结果
- **不足**：只有一两句摘要，缺乏方法和数据

对信息不足的论文，使用网络搜索补充（见第二步）。

### 第二步：网络搜索补充

对每篇信息不足的论文，搜索以下内容：
- 论文标题 + "方法" / "结果" / "arXiv"
- 重点获取：核心方法思路、量化指标（如准确率、提升幅度）、局限性

搜索时优先找原始论文页面或权威解读，不引用低质量二手内容。

### 第三步：按模板重构周报

使用下方模板，逐篇重写，然后组合成完整周报。

严格按照以下结构输出，不要随意增减模块：

```

## 导读

[2-3句话。说明本周选了哪几个方向，为什么值得关注。体现编辑视角，让读者感觉"有人帮我筛过了"。]

---

## [分类名称，如：水文遥感 · 深度学习]

### 📌 [论文中文译名] · [英文原名]

**问题**
[这篇文章解决了什么现实痛点？为什么现有方法不够用？2-4句，具体不抽象。]

**方法**
```

## 风格规范

- **专业术语保留英文**：RAG、LoRA、LSTM、DEM 等不强行翻译
- **数字要具体**："提升显著"→"BLEU提升4.2点"
- **段落控制在3-5句**：手机阅读，段落不能太长
- **emoji 点缀用**：仅用于固定字段标记（📌🤖💻🔭👥🔗），正文不滥用
- **中文为主**：论文标题给出中文译名，括号内保留英文原名
- **编辑语气**：不是机器摘要，是"有人读过后告诉你值不值得看"

---

## 质量检查

输出前自检：
- [ ] 每篇论文都有具体数字结果，不只是"表现优异"
- [ ] 导读体现了本周主题逻辑，不是罗列标题
- [ ] 段落没有超过5句的长段
- [ ] 没有出现"值得关注"、"意义重大"等空话

---

## 论文分类规则

收到论文列表后，按以下规则自动归类。**不符合任何分类的论文直接跳过，不写入周报。**

### 分类定义

| 分类名 | 关键词 / 判断依据 |
|--------|------------------|
| **水文AI应用** | 径流预测、流量同化、降雨-径流、LSTM/深度学习+水文、数据同化、hydrological forecast |
| **遥感多模态** | 遥感大模型、多模态、地球观测、SAR/光学融合、earth observation、MLLM、remote sensing |
| **AI科研自动化** | 自动科学发现、Agent+科研、AGI/ASI路线图与演进分析、自主实验、LLM-based agent for science、超级智能、递归自我改进 |

### 跳过规则

以下类型的论文**不写入周报**（直接忽略）：
- 纯数学/理论推导，与水文或遥感无直接关联（如：流匹配理论、扩散模型理论）
- 与团队研究领域（水文、遥感、AI for Science）完全无关的论文

### 分类示例

- *Testing discharge assimilation strategies* → **水文AI应用**
- *Earth-OneVision: Extending Remote Sensing MLLMs* → **遥感多模态**
- *EurekAgent: Agent Environment Engineering for Scientific Discovery* → **AI科研自动化**
- *From AGI to ASI* → **AI科研自动化**（AGI/ASI演进路线属于此类，必须进正文）
- *A Theory on Flow Matching with Neural Networks* → ⛔ 跳过（纯理论，无领域关联）

## 示例

**不好的结果写法：**
> 实验表明该方法在多个数据集上表现优异，显著优于基线方法。

**好的结果写法：**
> 在中国 1962-2024 年数据集上，1公里分辨率的日径流重建 KGE 达到 0.87，比现有最优方法提升 12%；植被遮挡区域的洪水漏分误差从 41.41% 降至 1.82%。
