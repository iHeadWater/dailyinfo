## 后续接入与撤回

后续部署 DailyInfo 时，将生产端的 `DAILYINFO_DATA_ROOT` 与 MCP 两个只读挂载源对应，使生成和投递流程持续写入同一目录。先核对 UID、读取权限及日期/分类，再选一份真实成功推送内容完成读取验收。

只读 MCP 不接管生产、调度、备份或内容同步，也不自动读取其他服务器的数据。停止 `dailyinfo-mcp` 即可撤回本次入口，保留正式数据和认证文件；不操作原有四个服务。
